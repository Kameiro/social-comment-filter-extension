# 评论筛选云端服务

这是个人云端和商业客户自托管共用的 API 模板。个人模式部署在你的服务器；商业客户部署自己的实例，把插件中的 API 地址改为客户服务器地址。

## 启动

1. 准备 PostgreSQL，执行 `schema.sql`。
2. 复制 `.env.example` 为 `.env`，设置 `DATABASE_URL`、随机的 `JWT_SECRET` 和一次性随机的 `ADMIN_SETUP_TOKEN`。
3. 安装依赖：`npm install`。
4. 启动：`npm start`。
5. 打开 `https://你的域名/admin`，用 `ADMIN_SETUP_TOKEN` 创建首个管理员；初始化成功后立即从服务器环境中删除或轮换这个令牌。
6. 在管理后台创建普通账户，或让用户在评论数据库页面自行注册。

评论数据库页面提供普通的账户登录、账户注册和邮箱验证码登录。管理员后台只用于管理账户和服务，不提供给普通用户使用。

快手 Android Vector/LSPosed 模块也使用同一账户接口：登录调用 `/v1/auth/login`，状态校验调用 `/v1/auth/me`，本地快照写入 `/v1/sync/snapshot`。服务端按 `tenant_id` 和稳定资源 ID 幂等更新，手机端先保存本地数据，网络失败时不会删除或覆盖本机采集结果。

邮箱验证码可以先在 `.env` 中配置 SMTP：`SMTP_HOST`、`SMTP_PORT`、`SMTP_SECURE`、`SMTP_USER`、`SMTP_PASS` 和 `SMTP_FROM`。管理员登录 `/admin` 后，也可以在“SMTP 邮件配置”页面输入并验证 Brevo SMTP Key；页面保存的配置会加密写入 PostgreSQL，并优先于环境变量使用。SMTP Key 不会回显。验证码保存哈希值，10 分钟有效，最多尝试 5 次；发送接口同一邮箱同一用途 60 秒内只能请求一次。

管理后台提供首个管理员初始化、管理员登录、SMTP 邮件配置、普通账户创建、账户列表、套餐管理、订单查看和手动授权。所有管理接口都要求管理员 JWT，密码只保存为 bcrypt 哈希，不保存明文。

## 生产要求

请在 HTTPS 反向代理后运行，设置 `CORS_ORIGIN` 为扩展实际来源或管理站点来源，不要长期使用 `*`；为 PostgreSQL 做备份和最小权限配置。收费功能由服务端套餐、订单和订阅授权控制，插件不会自行判定支付成功。

## 收费系统

1. 在管理后台创建套餐。价格单位是分，支付入口必须是 HTTPS 地址；插件创建订单后会把 `orderId` 追加到该地址。
2. 当前版本提供“手动授权”作为线下收款和联调入口。真正上线时，应由支付平台服务端回调核验订单并更新 `billing_orders.status` 与账户订阅，不能只根据浏览器回跳开通。
3. `.env` 中将 `BILLING_ENFORCED` 保持为 `false` 可以先联调登录、套餐和订单页面；确认支付回调和退款/撤销流程后再改为 `true`。开启后，新普通账户默认获得 `BILLING_TRIAL_DAYS` 天试用，云端同步接口会拒绝过期或未授权账户。
4. 目前没有绑定具体支付平台，因此没有虚构支付宝、微信或 Stripe 的支付成功回调。接入具体平台时，新增服务端签名验签适配器即可，客户端接口无需信任支付结果。

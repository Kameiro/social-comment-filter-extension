# 快手 App 内评论数据库模块

适配基线：官方快手 Android `14.8.40.50567`、Android 16 ARM64、Vector 3090 / libxposed API 102。
交付形式为 Vector 模块 APK，不重打包快手，不修改登录、平台请求、签名或返回值。
当前模块版本为 `0.1.3`（versionCode 4），为开发版本，尚未在一加 13T / ReSukiSU 真机验收。

## 使用

快手中显示可拖动的“评论数据库”浮动入口。评论、帖子、用户、分析、任务都在原生 App 内管理。
单独的“快手评论采集”应用也可打开同一数据库；上级 `collector.command` 是 Mac 开发入口。

- 评论保存一级/二级、父 ID、作者、时间、真实点赞/回复、手机版公开的 IP 地区。昵称打开主页，评论数量打开用户评论历史。
- 在快手内容页连续双击屏幕，会弹出当前作品信息面板，显示账号、发布时间、时长、点赞/评论/收藏/分享、封面、音乐和文案；可复制文案、保存作品信息及保存封面。面板只读取当前页面已经加载的公开作品字段，不从历史帖子记录推断当前作品。
- 评论数据库顶部的“视频信息设置”可以控制发布地址、发布时间、时长、统计数据、作品信息、封面、音乐、文案和复制文案按钮，并可切换底部抽屉/居中对话框及时间格式；“当前图片”开关暂时保留为不可用状态，待图集模型接入后启用。
- 结果可按地区、公开性别、年龄、关键词和时间筛选排序；地区填写“北京、河北”表示任一地区。未知资料不从昵称、头像或评论猜测。
- 新建评论任务先确认作品 ID，再显示条件；帖子可选择后批量入队。同一作品不会同时创建重复活跃任务。
- 资料补充和发现为独立任务，提供目标进度、暂停、继续、停止及运行记录。
- 继续和重试保留同一任务数据及已完成阶段；登录、验证、限流阻塞不自动推进后面的队列。
- `pagingMode` 支持 `auto`、`native`、`ui`。快手 `14.8.40.50567` 的 `auto/native` 会调用 App 自己的 KMP 评论分页器加载一级评论，并调用原生回复展开；`ui` 才使用界面滚动。任务记录原生调用次数和 UI 滑动次数。
- 本机 HTTP 接口与界面共用数据和任务服务，详见 [API.md](API.md)；Node 客户端为 `client.mjs`。
- 顶部“共享账户”使用电脑端相同的云端账户。登录后本地数据仍先保存，再通过 HTTPS 自动同步到 `/v1/sync/snapshot`；账户面板可手动重试。密码不落库，令牌不显示在界面或诊断中。
- 云端同步失败不会删除本机数据；任务列表和账户面板会显示待同步或失败状态。
- Android 16/ColorOS 如果拦截快手进程解析本地 Provider，模块会回退到显式桥接通道。安装或升级后先打开一次“快手评论采集”应用，让前台桥接服务启动；之后快手进程可继续访问任务和数据库，服务不会依赖快手后台启动权限。

## 完整性

采集和筛选分离：先保存原始公开评论，再应用查询条件，不因暂时未知性别丢弃原始数据。
主评论与每个回复组分别确认 EOF。未知游标、页面不动、超时和数量接近均不能报告完成。
当前旧评论响应没有 `mHasMore` 字段，需要读取其原生 `hasMore()/getCursor()`；普通字段型响应也兼容。
平台总评论数可能包含不可见或已删除评论，仅作进度参考，不作为末页证明。

自然加载需要 App 前台，关闭后任务和数据保留，但不会继续操控其他页面。
重新打开可续跑；这不是无需 App 前台的后台接口爬虫，也不保证平台未公开的数据一定可获得。
查看全屏数据库时暂缓 UI 翻页；已绑定的原生分页器可以继续运行。UI 模式任务显示“等待返回快手”，可点“返回快手继续”关闭面板，不重建任务。
创建任务后回到快手页面运行，重新打开数据库可查看最新进度；“复制诊断”可复制任务状态和错误代码供本地排查。
评论数据来自原生接口响应。已适配版本可以直接调用 App 内存中的原生分页器；适配器不可用时，`auto` 会回到 UI 翻页，显式 `native` 会暂停并记录原因。本机任务控制接口仍只负责数据库和任务状态。
不绕过私密主页、登录、验证码或平台限制；不自动群发私信、点赞、发帖。

## 构建

```bash
node android/kuaishou-collector/test.mjs
node android/kuaishou-collector/build.mjs
adb install -r android/runtime/collector/kuaishou-collector-debug.apk
```

使用 Java 21 和 Android SDK 36 的 javac、D8、aapt2、zipalign、apksigner，无需 Gradle。
libxposed API 102 为校验哈希的编译依赖，不打入 APK。NanoHTTPD 2.3.1 解析 HTTP，许可证随 APK 附带。
在 Vector 中启用模块并应用推荐作用域“快手”和模块自身，随后重启快手进程，不清除数据。
升级时覆盖安装模块，不卸载、不清除快手或模块数据；安装后强行停止快手再打开，确保进程加载新构建。内嵌数据库使用 App 内 Dialog，不要求系统“悬浮窗”权限。
Hook 探针必须实际显示 `hook-active / API 102`；加载日志不能替代数据链路验收。

## 手机面板操作更新

- 顶部“共享账户”使用同一云端账户登录，显示登录状态、上次同步时间和失败原因；不要输入 Cookie 或本机接口密钥。密码只在登录请求中使用。
- 采集条件中的分页模式可选“自动（优先原生）”“原生接口”“页面滚动”。这是任务意图，任务详情仍以实际 `pagingDriver`、原生调用次数和 EOF 证据显示结果。
- 电脑端浏览器扩展和手机模块共用云端账户概念，但不共享平台登录态或本机回环 API 密钥。完整边界与字段见项目根目录 `UNIFIED_PRODUCT.md`。

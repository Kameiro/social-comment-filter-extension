# 评论筛选助手

这个 Chrome 扩展用于筛选当前抖音或小红书帖子页面已经加载出来的评论文本。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择这个文件夹：`social-comment-filter-extension`。
5. 打开抖音或小红书帖子页面。
6. 点击 Chrome 工具栏里的“评论筛选助手”图标。

## 安卓平板（Helium / Titanium Browser）

可以使用。Helium Android 已更名为 Titanium Browser；其官方说明支持 Chrome 扩展，并可在 `chrome://extensions` 开启开发者模式后加载已解压扩展。

1. 在电脑的扩展目录中运行 `node build-helium-android.mjs`，会生成 `helium-android-extension` 文件夹。
2. 将整个 `helium-android-extension` 文件夹复制到安卓平板并解压，不要只复制里面的单个文件。
3. 在 Helium/Titanium 地址栏打开 `chrome://extensions`，开启 `Developer mode`，点击 `Load unpacked`，从系统文件选择器中选择该文件夹。
4. 在扩展管理页将“评论筛选助手（安卓）”固定到工具栏；打开抖音或小红书帖子后，从工具栏打开插件。

安卓端可使用：评论抓取、关键词/IP 属地/日期筛选、自动滚动、复制结果，以及写入飞书普通电子表格。

安卓端不提供：主页性别、年龄、所在地核验；删除已确认男性；按目标女性人数停止。这些功能依赖电脑上的本地 Node/Playwright 服务，Android 浏览器无法运行该服务。批量任务会逐个打开帖子，移动端浏览器可能会因后台页面节流而比电脑端慢，建议一次处理少量链接。

详细的平板安装、首次测试和排错步骤见 [安卓使用说明](ANDROID.md)。

需要在平板本机试验浏览器核验环境时，参见 [Termux 环境教程](TERMUX.md)。

## 使用

- `批量帖子链接` 留空：扫描当前打开的帖子。
- `批量帖子链接` 填多行：一行一个抖音或小红书帖子链接，插件会逐个打开、扫描、关闭，并合并结果。
- 结果里会带上 `帖子链接`，方便写入飞书后知道评论来自哪个帖子。
- 支持关键词、排除关键词、IP 属地、最近天数、自动滚到底或滚动上限、追加/重新搜索。抖音和小红书都会在翻页过程中由独立后台浏览器核验已加载评论用户的公开性别标记，确认男性立即从结果删除；小红书同时识别公开页面的 `#male`、`#female` 图标。“目标女性用户数”留空时验证全部，填写人数后达到目标即停止翻页。
- 支持写入飞书普通电子表格，不再使用多维表格。
- 性别核验使用 `playwright-worker` 独立无头浏览器渲染主页后读取最终 DOM，不会打开 Chrome 标签页或抢占前台。独立后台浏览器未登录或遇到平台验证时，会跳过该主页的资料核验。
- 点击“开始扫描”后，任务由扩展后台继续运行；关闭插件弹窗不会停止任务。
- 抖音或小红书页面右侧会显示任务浮窗：可拖动，松开后会自动吸附到左侧或右侧；浮窗可以收起，也能直接停止任务。

## 说明

- 只读取当前页面 DOM 中已经展示或自然滚动加载出来的文本。
- 不调用隐藏接口，不逆向签名参数，不绕过登录、验证码或平台限制。
- 小红书和抖音页面结构都可能变化，如果某个平台突然抓不到评论，先点“诊断评论容器”，把输出结果发给我继续微调。

## Playwright 后台服务

首次安装依赖仍需执行一次：

```bash
npm install
npx playwright install chromium
```

安装依赖后，先双击一次扩展目录中的 `安装自动后台服务.command`。重新加载 Chrome 扩展后，插件会在需要核验主页时自动启动后台服务，无需再双击启动文件或打开终端。需要登录独立后台浏览器时，可双击 `登录抖音.command` 或 `登录小红书.command`；平台验证码需要在该独立窗口中由用户手动完成。

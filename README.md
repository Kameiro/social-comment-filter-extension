# 评论筛选助手

## 账户与数据同步

项目支持仅本地保存、同步到你的服务器、同步到商业客户自托管服务器三种模式。新安装版本默认使用 `https://comment-filter.04210410.xyz`；首次使用可在评论数据库页面注册或登录账户。已登录后，扫描和主页资料任务完成会自动同步，评论数据库页面只显示同步状态和最近同步时间。

服务端模板位于 `services/cloud-server`：

1. 使用 PostgreSQL 执行 `services/cloud-server/schema.sql`。
2. 复制 `services/cloud-server/.env.example` 为 `.env`，设置数据库地址和随机 JWT 密钥。
3. 在 `services/cloud-server` 中运行 `npm install`，然后用 `npm run provision -- 邮箱 密码 客户名称` 创建账户。
4. 通过 HTTPS 反向代理运行 `npm start`。
5. 在评论数据库页面注册或登录账户；首次登录后插件会自动同步本机数据库，用户不需要手动触发同步或清空数据库。

商业客户可以部署自己的 `services/cloud-server`，数据表按 `tenant_id` 隔离。当前版本已完成账户登录和数据同步，支付回调、套餐管理后台和自动双向合并尚未实现。

这个 Chrome 扩展用于筛选当前抖音、小红书或快手帖子页面已经加载出来的评论文本。

## 项目结构

```text
extension/                 浏览器扩展源码和 manifest
  background/              MV3 service worker
  popup/                   工具栏弹窗
  dashboard/               本地评论数据库面板
  content/common/          公共脚本、接口捕获、任务浮窗和私信
  content/platforms/       抖音、小红书、快手平台采集器
  data/                    IndexedDB 数据层
  cloud/                   云端同步客户端
services/                  Playwright、云端 API、Native Messaging 服务
scripts/                   安卓构建和 macOS 启动脚本
docs/                      安卓和 ZeroTermux 文档
dist/                      安卓扩展发布产物
```

平台采集器只放页面结构和平台差异；跨平台逻辑放在 `extension/content/common`，数据库操作放在 `extension/data`。修改桌面扩展后，通过 `scripts/build-helium-android.mjs` 生成 `dist` 中的安卓扁平包。

## 版本区分

- **电脑本机 Chrome/Chromium 版**：在 `chrome://extensions` 加载项目中的 `extension` 文件夹。本机测试弹窗、评论抓取和 Playwright 主页资料核验时使用这一版。
- **安卓 Helium/Titanium 版**：直接加载 `dist/helium-android-extension` 文件夹即可；`dist/helium-android-extension.zip` 只用于复制、备份或发布。这一版只给支持 Chrome 扩展的第三方 Chromium 浏览器加载。
- 修改电脑端源码后，运行 `node scripts/build-helium-android.mjs` 更新 `dist/helium-android-extension`；需要 ZIP 时，在 `dist` 目录执行 `zip -qr -FS helium-android-extension.zip helium-android-extension`。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `extension` 文件夹。
5. 打开抖音、小红书或快手帖子页面。
6. 点击 Chrome 工具栏里的“评论筛选助手”图标。

修改桌面版文件后，在 `chrome://extensions` 对电脑端扩展点击“重新加载”，再重新打开插件弹窗。

## 安卓平板（Helium / Titanium Browser）

可以使用。Helium Android 已更名为 Titanium Browser，本质上是支持 Chrome 扩展的第三方 Chromium 浏览器，可在 `chrome://extensions` 开启开发者模式后直接加载已解压扩展文件夹。

1. 在项目根目录运行 `node scripts/build-helium-android.mjs`，会生成 `dist/helium-android-extension` 文件夹。
2. 将整个 `dist/helium-android-extension` 文件夹复制到安卓平板；如果通过 ZIP 传输，再先解压，不要只复制里面的单个文件。
3. 在 Helium/Titanium 地址栏打开 `chrome://extensions`，开启 `Developer mode`，点击 `Load unpacked`，从系统文件选择器中选择该文件夹。
4. 在扩展管理页将“评论筛选助手（安卓）”固定到工具栏；打开抖音、小红书或快手帖子后，从工具栏打开插件。

安卓端可使用：抖音、小红书和快手评论抓取、关键词/IP 属地/日期筛选、接口分页和复制结果。评论数据库的“发现帖子”自动搜索需要电脑端独立 Playwright 后台服务，安卓端暂不启动主浏览器外的搜索任务。

安卓端不提供：主页性别、年龄、所在地核验；删除已确认男性；按目标女性人数停止。这些功能依赖电脑上的本地 Node/Playwright 服务，Android 浏览器无法运行该服务。批量任务会逐个打开帖子，移动端浏览器可能会因后台页面节流而比电脑端慢，建议一次处理少量链接。

详细的平板安装、首次测试和排错步骤见 [安卓使用说明](docs/ANDROID.md)。

需要在平板本机准备后续性别核验所需的后台浏览器环境时，参见 [ZeroTermux 最短教程](docs/TERMUX.md)。当前教程只做环境验证，不会改变插件的评论抓取功能。

## 使用

- `批量帖子链接` 留空：扫描当前打开的帖子。
- `批量帖子链接` 填多行：一行一个抖音、小红书或快手帖子链接，插件会逐个打开、扫描、关闭，并合并结果。
- “评论数据库”后台的“发现帖子”页：输入关键词后，插件会交给独立的 Playwright 后台浏览器打开抖音搜索页，监听抖音自己的搜索响应，提取帖子数据并去重；不会在你当前使用的浏览器中打开搜索标签页。结果会和历史搜索结果合并保存。你可以查看点赞、评论、转发、收藏和是否已经抓取过评论，再勾选帖子批量抓取评论及用户资料。该功能不需要第三方 API 或额外令牌。
- 自动发现使用抖音搜索页的自然加载和有限滚动，遇到验证码或风控会停止本次发现；后台列表目前统一支持抖音、小红书、快手的数据展示，自动搜索接口当前先接入抖音，其他平台可继续接入后复用同一选择和批量抓取流程。
- 快手帖子通常使用 `https://www.kuaishou.com/short-video/{photoId}` 格式；快手短链请先在浏览器中打开并等待跳转到完整帖子页，再复制最终地址。快手当前只处理页面已经加载的评论，不会模拟滚动；快手接口分页暂未接入。
- 结果里会带上 `帖子链接`，方便复制后区分评论来自哪个帖子。
- 抖音从搜索结果弹层打开的地址（例如带 `modal_id` 的 `/search/...` 或 `/jingxuan?...`）会自动转换成实际帖子地址 `https://www.douyin.com/video/{modal_id}`；搜索页只作为数据库中的来源页保存，不会再写入评论的帖子链接。
- 支持关键词、排除关键词、IP 属地、最近天数、接口页数上限、追加/重新搜索。接口页数上限为 `0` 时表示读取到平台明确返回没有下一页；目标性别人数为 `0` 时表示不因命中数量提前停止，获取全部符合筛选条件的评论。抖音和小红书会复用当前页面已经发出的评论请求模板，在同一登录会话中按 `cursor` 自动分页；签名、Cookie 和动态令牌仍由网页自身生成。评论任务不再模拟滚动，也不会通过滚动触发加载。没有捕获到可复用接口时，只处理页面当前已经加载的评论并明确提示结果不完整。抖音同时按评论 ID 分页读取折叠回复；小红书按回复接口分页读取折叠回复。抖音和小红书都会在接口分页过程中由独立后台浏览器核验已加载评论用户的公开性别标记，确认男性立即从结果删除；小红书同时识别公开页面的 `#male`、`#female` 图标。
- 数据库中的抓取审计只有在接口明确返回 `has_more=false`、等价的 `hasNext=false` 或 `no_more` 游标时才显示“已确认到末页”。接口字段缺失、游标重复、游标缺失、页数上限、验证码和接口失败都会显示“未确认到末页”，不会把部分结果误报为完整。
- 接口读取不会绕过登录、验证码或平台限流。抖音网页请求会带页面实时生成的签名参数，小红书评论接口也依赖页面会话，因此插件捕获当前页面已经发出的真实请求，不保存固定签名，也不直接拼接长期失效的接口地址。
- 如果接口分页触发平台人机验证，任务会暂停为“等待平台验证”，保存已经获取的评论并保留当前帖子页面，不会自动关闭验证页，也不会继续重放接口。请在当前页面手动完成验证，再点击浮窗或插件弹窗中的“验证完成，继续抓取”；恢复使用原任务编号并按评论 ID 去重。
- 小红书通过回复接口读取折叠回复，并继续处理同一组回复的后续分页；主评论和回复按评论 ID 去重。回复接口失败时保留已有结果并提示未加载成功的内容，不会改用页面滚动或模拟点击展开。
- 扫描结果会同时保存到当前浏览器的 IndexedDB 本地数据库；点击“打开评论数据库”可按帖子、评论和用户查看、搜索、筛选和复制。旧版 `chrome.storage.local` 结果首次打开数据库时会自动迁移。
- 在“评论数据库”的“用户”页可以点击“私信”。插件会根据该用户最近评论过的帖子和评论生成可编辑草稿，确认后在后台打开用户主页并尝试发送；成功后会记录为“已私信”，避免插件重复发送。这个状态只代表本机插件记录，平台外发送的历史不会自动同步。
- 抖音私信复用已登录网页的 IM SDK，打开会话后直接发送，不再模拟输入和点击发送按钮；电脑端与安卓 Chromium 扩展使用同一流程。平台 SDK 仍依赖浏览器登录状态，并非无需登录的独立接口。目标会话不一致、SDK 不可用或历史中已有相同内容时不会发送；发送结果不明确时保留聊天页且阻止重试，请先检查聊天记录。小红书和快手暂时保留页面操作方式。
- 本地 IndexedDB 是当前浏览器的缓存；登录默认云端账户后，扫描和主页资料任务完成会自动同步到服务器，电脑端和安卓端可以通过同一账户使用云端数据。
- 性别核验优先通过扩展在当前 Chromium 会话中后台读取抖音主页公开资料，不切换前台；当前浏览器没有可复用的抖音标签页时才创建一个非活动临时标签页并在读取后关闭。当前会话读取不到时，再使用 `services/playwright-worker`：后台服务默认先探测本机 Chromium 的 CDP 调试端口 `9222`，连接不到时回退独立无头浏览器。CDP 模式只创建和关闭自己的临时页面，不关闭用户浏览器或用户已有页面；快手评论抓取暂不提供主页性别核验。独立浏览器没有抖音登录态时，第一次进行性别核验会自动弹出独立登录窗口；完成登录后重新执行主页资料核验，不能把主浏览器登录状态当成独立浏览器登录状态。
- 抖音主页资料优先由独立 Playwright 后台浏览器复用主页加载时真实发出的 `/aweme/v1/web/user/profile/other/` 响应，严格核对目标 `sec_uid` 后读取公开的性别、年龄、地区、昵称、UID 和部分统计字段；接口读取失败时才回退到已打开的抖音页面会话及 SSR/DOM 资料。成功检查的抖音用户资料缓存 24 小时；未公开的年龄/所在地保持空白，不会因字段为空而在每次自动任务中重复访问。接口仍依赖平台登录态，不重建固定签名，也不绕过登录或验证。
- 小红书主页资料只读取资料区：性别兼容完整 SVG 文件路径中的 `#male` / `#female`，年龄只读取公开的年龄标签，主页所在地优先读取地区标签（例如“北京丰台”），不把 IP 属地当作居住地，也不从简介或笔记推断年龄。未公开的信息保持空白。可公开访问的主页会先尝试无登录读取，无法加载时再提示登录或读取失败。
- 点击“开始扫描”后，任务由扩展后台继续运行；关闭插件弹窗不会停止任务。
- 抖音或小红书页面右侧会显示任务浮窗：可拖动，松开后会自动吸附到左侧或右侧；浮窗可以收起，也能直接停止任务。

## 说明

主页性别核验首次返回“独立后台浏览器尚未登录”时，服务会自动启动一次可见登录窗口。完成抖音登录后，回到评论数据库点击“按此条件更新”或“补充主页资料”重新执行；旧任务不会把登录前的“未知”自动改写成已确认性别。登录失败、验证码或主页未公开性别时，任务会保留“未知”并显示具体失败原因。

- 只读取当前页面已经展示或自然加载出来的公开评论数据。
- 不保存固定接口签名，不逆向签名参数，不绕过登录、验证码或平台限制。
- 抖音、小红书和快手页面结构都可能变化，如果某个平台突然抓不到评论，先点“诊断评论容器”，把输出结果发给我继续微调。

## Playwright 后台服务

首次安装依赖仍需执行一次：

```bash
npm install
npx playwright install chromium
```

安装依赖后，先双击 `scripts/mac/安装自动后台服务.command`。安装脚本会安装 `~/Library/LaunchAgents/com.commentfilter.playwright-worker.plist`，让 Playwright 后台服务在登录 macOS 后自动运行，并把 Native Messaging Host 注册到 Chrome、Ego Lite、Chromium 和 Edge 作为备用启动方式。这样插件只要能安装在 Chromium 系浏览器中，就可以连接本机 `127.0.0.1:38765`，不依赖浏览器是否支持 Native Messaging。要复用当前浏览器登录态，仍可让 Ego/Chrome 开启本机远程调试（默认端口 `9222`）；没有 CDP 时，发现帖子会回退到当前浏览器的后台标签页复用登录态。设置 `COMMENT_FILTER_BROWSER_MODE=cdp` 可强制只使用共享浏览器，设置为 `isolated` 可强制使用独立后台浏览器。若要停止常驻服务，可执行 `launchctl bootout gui/$(id -u)/com.commentfilter.playwright-worker`；重新运行安装脚本即可恢复。

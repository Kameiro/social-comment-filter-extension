# 安卓平板使用说明

此说明适用于 Helium Android（现名 Titanium Browser）这个支持 Chrome 扩展的第三方 Chromium 浏览器。

本文件只适用于安卓 Helium/Titanium。电脑本机 Chrome/Chromium 请加载项目中的 `extension` 文件夹；电脑端问题也请先在电脑端扩展上复现和测试。

## 云端部署

安卓端同样支持本地、你的服务器和客户自托管三种数据模式。新安装版本默认使用 `https://comment-filter.04210410.xyz`，首次使用可在评论数据库页面注册或登录账户；登录后扫描完成会自动同步，评论数据库页面只显示同步状态和最近同步时间。服务 API 必须使用 HTTPS。

## 当前可用功能

- 抖音、小红书和快手当前帖子评论抓取
- 小红书折叠回复自动展开、分页加载和评论去重
- 关键词、排除关键词、IP 属地和最近天数筛选
- 评论数据库后台的帖子数据汇总和勾选批量抓取
- 接口分页、停止任务、复制 TSV 结果
- 页面内任务浮窗

电脑端扫描时，将“接口页数上限”设为 `0` 表示持续读取到平台明确返回没有下一页；将“目标性别人数”设为 `0` 表示不因命中数量提前停止，获取全部符合筛选条件的评论。只有接口明确返回没有下一页时，任务才会标记为“已确认到末页”；遇到验证码、接口失败、游标异常或人为页数上限时，会保留“未确认到末页”。

如果抖音或小红书接口分页触发人机验证，任务会显示“等待平台验证”并保留当前帖子页，不会自动关闭页面。请手动完成验证后，在任务浮窗或插件弹窗点击“验证完成，继续抓取”；点击“停止任务”则会保存已抓取结果并结束任务。
- 评论数据库面板：按帖子、评论和用户查看、搜索和复制
- 用户页单条私信：可编辑针对该用户评论内容生成的草稿，后台打开主页后发送，并记录本机已发送状态

安卓端不会运行电脑上的 Node/Playwright 后台服务。因此主页性别、年龄、所在地核验，删除已确认男性，以及目标女性人数停止功能会自动隐藏；结果里的性别会保持“未知”。

## 安装

1. 将 `dist/helium-android-extension` 文件夹复制到平板；如果通过网络或文件管理器传输 ZIP，再在平板上解压。
2. 打开 Helium/Titanium，在地址栏输入 `chrome://extensions`。
3. 打开 `Developer mode`（开发者模式）。
4. 点击 `Load unpacked`（加载已解压扩展），在系统文件选择器中选择解压出来的 `helium-android-extension` 文件夹。
5. 在扩展管理页将“评论筛选助手（安卓）”固定到工具栏。
6. 打开一个抖音、小红书或快手帖子，再从工具栏打开插件。
7. 在插件中点击“打开评论数据库”，可查看已保存的帖子、评论和用户信息。

电脑端打开“评论数据库”后切换到“发现帖子”页，填写关键词并点击“发现帖子”。搜索由独立的 Playwright 后台浏览器执行，不会在当前浏览器中新增抖音搜索标签页；结果会显示帖子数据和是否已经获取过评论，勾选需要处理的帖子后点击“抓取选中帖子评论和用户”。当前自动搜索接入抖音，小红书和快手先保留统一数据展示入口。安卓端没有 Playwright 服务，因此暂不执行自动搜索发现。

电脑端源码更新后，在项目根目录运行 `node scripts/build-helium-android.mjs`，然后在扩展管理页对已加载的 `dist/helium-android-extension` 重新加载即可，不需要每次生成 ZIP。只有要复制、备份或发布时，才在 `dist` 目录执行 `zip -qr -FS helium-android-extension.zip helium-android-extension`。安卓扩展不会自动同步电脑端源码。

如果浏览器没有显示 `Load unpacked`，请确认安装的是支持扩展的 Helium/Titanium Android 版本，并先启用开发者模式。

## 首次测试

1. 在一个评论较多的帖子中，手动打开评论区。
2. 先将“接口页数上限”设为 `2`，关键词和 IP 属地留空。
3. 点击“开始扫描”，确认任务浮窗的接口页数和命中数会变化，页面本身不会被插件滚动。
4. 点击“复制结果”，粘贴到任意文本编辑器，确认第一行包含表头和帖子链接。
5. 再测试关键词、地区和日期限制。

移动端批量任务会依次打开帖子；部分 Android 浏览器会暂停后台标签页，建议首次只放 1 到 3 个链接测试。

在“评论数据库”的“用户”页点击“私信”可以编辑草稿并发送。插件只允许对本机尚未记录私信的用户显示发送按钮；平台账号必须已登录，并且该用户页面确实提供私信入口。平台没有找到输入框或发送按钮时，会显示失败原因，不会标记为已发送。

## Termux 计划

Termux 可以作为平板本地的独立核验服务：插件请求 `127.0.0.1`，Termux 中的 Chromium/Selenium 或 Puppeteer 打开主页并读取男女图标。这个模式需要单独安装 Termux、浏览器运行时和登录资料，目前尚未随本扩展包自动安装。

在该模式完成前，安卓包不会尝试启动 Termux，也不会在后台打开任何主页。
